# App Store release

Jolito is preparing its first paid iPhone and iPad release: US$2.99 once,
with Apple-managed equivalent prices in eligible worldwide storefronts.
The web app remains free. Bundle ID: `to.joli.app`; initial version: `1.0`.

## Status

Not submitted. Enrollment, signing credentials, a signed TestFlight build,
physical-device testing, and Apple review are still outstanding. An unsigned
iOS compilation or a successful web build does not establish release readiness.

Implementation and verification details will be added in this release PR.
